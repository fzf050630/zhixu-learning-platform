# 高等数学 · 交互可视化

考研数学（一）高等数学的交互学习项目，内容严格按《2026 年全国硕士研究生招生考试数学考试大纲》数学（一）· 高等数学（p.6–p.15）构建，共八章。

## 内容范围

| 章 | 内容 | 主要可视化 |
| --- | --- | --- |
| 一 | 函数、极限、连续 | 极限过程、无穷小的阶、间断点类型 |
| 二 | 一元函数微分学 | 割线趋近切线、单调与极值、凹凸与渐近线、曲率圆 |
| 三 | 一元函数积分学 | 黎曼和、变限积分、反常积分、旋转体体积 |
| 四 | 向量代数和空间解析几何 | 向量运算、平面与直线 |
| 五 | 多元函数微分学 | 偏导数与截线、方向导数与梯度、拉格朗日乘数法 |
| 六 | 多元函数积分学 | 二重/三重积分、格林公式、散度与通量 |
| 七 | 无穷级数 | 部分和收敛、幂级数、泰勒逼近、傅里叶级数 |
| 八 | 常微分方程 | 斜率场、二阶常系数方程、欧拉法 |

每章附「大纲原文（逐字摘录）」与「大纲覆盖自检表」，可逐条核对不漏知识点。

## 目录结构

```text
index.html                    入口
assets/css/main.css           样式
assets/js/lib/draw.js         Canvas 绘图引擎
assets/js/lib/stats.js        统计与数值工具
assets/js/widgets/ui.js       控件外壳
assets/js/widgets/calc1-8.js  各章交互组件
assets/js/app.js              路由 / 渲染 / KaTeX / 进度 / 搜索
assets/vendor/katex/          KaTeX 数学公式渲染（本地）
content/syllabus.js           大纲原文、结构与覆盖映射
content/ch1-8.js              各章知识块、公式、例题与易错点
```

## 约定

- 本目录依赖根目录的 `platform/`，交付时请使用整站 `dist/`。
- 学习进度保存在浏览器本地键 `zhixu-calculus-progress-v1`。
- 公式用 `\( ... \)` 与 `\[ ... \]` 定界，由 KaTeX 渲染。

## 本地预览

在仓库根目录执行 `npm run dev`，访问 http://127.0.0.1:8766/ 后选择「高等数学」。
