# 操作系统 · 交互可视化

408 操作系统的交互学习项目，知识主线参考王道《计算机操作系统》，覆盖第 1~5 章。

## 内容范围

| 章 | 内容 | 主要可视化 |
| --- | --- | --- |
| 1 | 计算机系统概述 | 用户态/内核态与系统调用、操作系统结构 |
| 2 | 进程与处理机调度 | 进程状态转换、调度算法甘特图、信号量 PV、银行家算法 |
| 3 | 内存管理 | 连续分配、分页/分段地址转换、页面置换算法 |
| 4 | 文件管理 | 文件物理结构与索引寻址、目录树、位示图与成组链接 |
| 5 | 输入/输出管理 | I/O 软件层次、磁盘调度、单/双缓冲时间 |

## 目录结构

```text
index.html                    入口
assets/css/main.css           样式
assets/js/lib/draw.js         Canvas 绘图引擎
assets/js/widgets/ui.js       控件外壳
assets/js/widgets/os1-5.js    各章交互组件
assets/js/app.js              路由 / 渲染 / 进度 / 搜索 / 主题
content/syllabus.js           章节结构与考点覆盖
content/ch1-5.js              各章知识块、例题、易错点
```

## 约定

- 本目录依赖根目录的 `platform/`，交付时请使用整站 `dist/`。
- 学习进度保存在浏览器本地键 `zhixu-operating-systems-progress-v1`。
- 可播放组件在离开页面时由 `Draw.prune()` 释放计时器与观察器。

## 本地预览

在仓库根目录执行 `npm run dev`，访问 http://127.0.0.1:8766/ 后选择「操作系统」。
