# 知识性错误审阅清单

> 审阅范围：`content/ch1.js ~ ch8.js` 全部知识点、公式与例题（数值已逐一验算）。
> 审阅日期：2026-09-10

## 一、确凿的知识性错误（建议必须改）

### 1. `content/ch1.js:117`（1.2 常用恒等式「并化互斥」）

写的是：

```
A∪B = A∪(B−AB) = A∪BĀ = A∪BĀB̄
```

最后一项错误：`BĀB̄ = ∅`，故 `A∪BĀB̄ = A ≠ A∪B`。最后一个 `\bar B` 是多余的，正确止于 `A∪B\bar A`（或改写为 `=B\cup A\bar B`）。

### 2. `content/ch1.js:161`（1.2 pitfalls 第 3 条）

原文：「A−B 与 B−A 一般不相等，**也不互斥**（都可以为空）」。

错误。`(A−B)∩(B−A) = AB̄∩BĀ = ∅` 恒成立，两者**永远互斥**；「都可为空」恰恰不违反互斥。

应改为：「A−B 与 B−A 一般不相等，但恒互斥（交集必为空）」。

### 3. `content/ch8.js:167`（例 8.4 注释）

原文：「若把 n 增大到 64，…β 会降到约 0.063」。

计算错误。n=64 时拒绝域随之变为 `X̄ > 1.645/8 ≈ 0.2056`，故

```
β = Φ((0.2056 − 0.6)/0.125) = Φ(−3.155) ≈ 0.0008
```

0.063 是沿用 n=16 的旧临界值 0.41125 未更新的结果（Φ(−1.51)≈0.066）。

### 4. `content/ch3.js:429` vs `content/ch3.js:470`（例 3.12 记号自相矛盾）

3.5 节定义（及大纲原文）为 `N(μ₁,σ₁²; μ₂,σ₂²; ρ)`，但例 3.12 解答按 `N(μ₁,μ₂; σ₁²,σ₂²; ρ)` 的顺序解读 `N(1,2;4,9;0.5)`（得 μ₁=1, μ₂=2, σ₁²=4, σ₂²=9）。

按页面自定义记号应为 μ₁=1, σ₁²=2, μ₂=4, σ₂²=9，与解答矛盾。需把题面改成 `N(1,4; 2,9; 0.5)` 或统一记号。

### 5. `content/ch3.js:591`（例 3.16 注释）

原文：「这是极大似然估计中 θ̂=max Xᵢ 的理论基础（**见第八章**）」。

MLE 在**第七章**（例 7.7 即 U(0,θ) 的 MLE），第八章是假设检验。交叉引用错误。

## 二、概念/表述不严谨（建议修改）

### 6. `content/ch1.js:84`（1.1 pitfall）

原文：「必然事件与不可能事件**不是**随机事件，但为了运算方便把它们也纳入事件之列」。

自相矛盾且与主流教材（浙大《概率论与数理统计》等）不符：通行处理是 Ω 与 ∅ 是（两个特殊的）随机事件。

### 7. `content/ch2.js:69`（2.1 易错卡）

原文：「F(x)=P{X≤x} 是**左闭右闭**的累积」。

措辞错误。累积区间是 (−∞, x]，只有「右端点闭」，无「左闭」可言。

### 8. `content/ch1.js:560`（1.8 结论 3）

原文：「则 A 与自身独立 ⟺ 不成立（…）」。

病句，应为「A 与自身独立不成立」（数学内容本身正确：0<P(A)<1 时 P(A²)=P(A)≠P(A)²）。

### 9. `content/ch2.js:231`（2.3 几何分布辨析）

原文：「**考研大纲采用**第一种定义（k 从 1 开始）」。

大纲仅列「几何分布」并未规定定义形式，表述过强；只能说「考研教材（浙大版）通用 k≥1 的定义」。
