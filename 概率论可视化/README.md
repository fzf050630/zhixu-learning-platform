## 如何打开

**方式一（推荐，双击即用）**

直接双击 `index.html`，用任意现代浏览器（Chrome / Edge / Firefox）打开即可，无需联网、无需安装、
无需构建。所有第三方资源（KaTeX 公式渲染）均已本地化到 `assets/vendor/`。


## 功能

- **大纲覆盖自检表**：首页逐条列出已完成章节的全部考试内容，并链接到对应小节，用于机械化核对「不漏知识点」。
- **大纲原文**：首页折叠区附考试内容与考试要求逐字摘录。
- **学习进度**：每个知识点可标记「已掌握」，进度保存在浏览器 localStorage。
- **深色模式**、**一键打印 / 导出 PDF**、**知识点搜索**（快捷键 `/`）。
- **响应式**：适配桌面与移动端。

## 扩展方式

新增一章只需三步：

1. 在 `content/` 下新建 `chN.js`，注册 `window.CHN = { id, no, title, sections:[…] }`；
2. 在 `assets/js/widgets/` 下新建 `chN.js`，实现 `window.WIDGETS.xxx = function(host){…}`；
3. 在 `index.html` 引入这两个脚本，并把 `content/syllabus.js` 中 `probStructure` 的该章
   `status` 改为 `'done'`，同时补充 `official` 与 `coverage`。

`assets/js/app.js` 会自动扫描 `window.CH1…CH8` 并生成目录与首页卡片。
