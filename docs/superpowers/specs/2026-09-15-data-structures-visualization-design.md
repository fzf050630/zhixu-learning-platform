# 数据结构考研算法可视化系统设计

## 1. 目标

以 `27王道《数据结构》高清带书签.pdf` 为内容范围依据，制作一个面向考研复习的离线算法可视化网站。首版只呈现关键章节中的算法过程，不制作知识点长文、知识框架、题库、章节测试或教材原题复刻。

用户通过预设案例观察算法执行。每个步骤必须同时更新算法动画、C 语言伪代码高亮、当前数据状态和简短操作说明。

## 2. 项目组织

当前目录整理为两个相互独立的项目：

```text
数学建模/
├─ 概率论可视化/
│  ├─ index.html
│  ├─ assets/
│  ├─ content/
│  ├─ _work/
│  ├─ README.md
│  ├─ wrong.md
│  └─ 26考研数学大纲(1).pdf
└─ 数据结构可视化/
   ├─ index.html
   ├─ assets/
   ├─ content/
   ├─ README.md
   └─ 27王道《数据结构》高清带书签.pdf
```

两个项目均可直接双击 `index.html` 离线运行，不依赖构建工具、包管理器或网络资源。整理目录时保持概率论项目的内部相对路径不变。

## 3. 首版内容范围

### 3.1 线性表

- 顺序表插入与删除
- 单链表插入、删除与逆置

### 3.2 栈与队列

- 顺序栈入栈与出栈
- 循环队列入队与出队
- 括号匹配
- 中缀表达式转后缀表达式

### 3.3 树

- 二叉树先序、中序、后序遍历
- 二叉树层序遍历
- 哈夫曼树构造
- 并查集查找与合并

### 3.4 图

- 邻接矩阵与邻接表表示转换
- 广度优先搜索与深度优先搜索
- Prim 与 Kruskal 最小生成树
- Dijkstra 与 Floyd 最短路径
- 拓扑排序
- 关键路径

### 3.5 查找

- 折半查找
- 二叉排序树查找、插入与删除
- AVL 树失衡与旋转
- B 树插入与分裂
- 散列表及冲突处理

### 3.6 排序

- 直接插入排序
- 希尔排序
- 冒泡排序
- 快速排序
- 简单选择排序
- 堆排序
- 归并排序
- 同一预设序列上的过程对比

首轮扩展优先完成层序遍历、哈夫曼树、并查集、DFS、Prim、Kruskal、Floyd、拓扑排序、关键路径、BST、AVL、散列表、直接插入排序与归并排序。完成后站点包含 26 个可视化实验。

## 4. 页面与交互设计

首页只展示六个章节入口以及各章可视化实验卡片，不展示长篇知识梳理。

实验页采用统一四区布局：

1. 算法动画主画布；
2. C 语言伪代码面板，当前执行行高亮；
3. 当前状态与单步操作说明；
4. 上一步、下一步、播放/暂停、重置和速度调节控制栏。

桌面端使用画布与代码并排布局。窄屏设备改为画布、代码、状态、控制栏纵向排列。画布按容器尺寸与设备像素比重绘，保证文字与连线清晰。

所有实验使用预设案例。首版不提供任意数据输入、代码编辑或在线运行环境。

## 5. 技术架构

项目采用原生 HTML、CSS、JavaScript 和 Canvas。树、图中的标签、提示或无障碍文本可使用少量 HTML 覆盖层，但不引入第三方图表库或前端框架。

算法执行器只负责根据预设案例生成步骤快照，不操作 DOM 或 Canvas。可视化渲染器只根据当前快照绘制，不实现算法逻辑。播放器负责步骤索引、自动播放、暂停、速度、重置与订阅通知。页面层负责路由、导航和组件装配。

## 6. 步骤快照协议

所有算法输出统一结构的步骤数组：

```js
{
  id: "quick-sort-partition-4",
  line: 6,
  message: "右指针向左寻找小于枢轴的元素",
  state: {
    array: [27, 13, 35, 8, 19],
    active: [0, 4],
    pivot: 27
  }
}
```

每个步骤必须是可独立渲染的完整快照，而非依赖前一步的增量命令。这样“上一步”和随机跳转不会产生状态漂移。

数据流为：

```text
预设案例
→ 算法执行器生成完整步骤快照
→ 播放器选择当前步骤
→ 动画、状态说明和伪代码高亮同步更新
```

## 7. 视觉规则

- 中文界面使用微软雅黑；代码、行号、步骤计数与数字使用随项目打包的 JetBrains Mono。
- 正文字号不低于 15px，代码字号约 13.5px，Canvas 数字与标签约 13-17px。
- 数组使用连续单元格，颜色区分已处理、比较中、枢轴和已确定区域。
- 链表使用节点、指针端口和方向箭头，空指针明确标记为 `NULL`。
- 树使用稳定的层级布局；旋转或重构时保持节点身份与颜色不变。
- 图使用固定节点坐标，避免每一步重新布局导致用户失去位置记忆。
- 伪代码只高亮当前执行行；状态说明限制为一句动作与一句结果。
- 动画以理解状态变化为目标，不加入与教学无关的装饰效果。

## 8. 边界与异常处理

- 到达第一步或最后一步时禁用对应按钮。
- 连续点击、切换算法或重置时取消尚未完成的过渡动画。
- 自动播放到末尾后停止，不循环。
- 页面不可见时暂停播放，返回后由用户继续。
- 画布过窄时切换纵向布局，并允许复杂图结构横向滚动。
- 若某个实验初始化失败，显示实验级错误提示，不影响章节导航和其他实验。
- 教材 PDF 只作为范围依据，不在网页中整页嵌入，也不大段复制教材文字或原题。

## 9. 验证与完成标准

### 9.1 算法正确性

- 每个步骤生成器使用固定预设数据进行断言验证。
- 最终状态必须与对应算法的正确结果一致。
- 图算法验证访问顺序、边集合、距离数组或拓扑序等关键结果。
- 树算法验证结构约束，例如 BST 有序性、AVL 平衡因子和 B 树节点容量。

### 9.2 同步正确性

- 每个快照引用的伪代码行必须存在。
- 前进、后退、自动播放和重置后，画布、代码与说明显示同一快照。
- 快速重复操作不会跳步、叠加定时器或残留旧算法状态。

### 9.3 页面质量

- Chrome 与 Edge 可通过本地文件直接打开。
- 桌面和移动宽度下无文字遮挡、画布裁切或控制栏溢出。
- 切换章节、算法与主题后均可正常重绘。
- 概率论项目迁移后，其入口、样式、脚本、公式字体和学习进度功能保持正常。

## 10. 非目标

首版不包含用户自定义数据、题库、评分、账号、云同步、后端服务、在线编译器、教材全文搜索、知识点长文、视频课程或 PDF 阅读器。
