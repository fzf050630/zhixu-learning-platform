# 数学三课全量优化设计

日期：2026-09-30。状态：用户明确授权直接实施并发布。

## 目标

按“知识审计 → 内容丰富度 → 动画优化”的顺序，完整优化知序的考研数学一高等数学、线性代数、概率论与数理统计三课，并发布至 `/math-modeling/`。2026 年数学一大纲中的每条考试内容与考试要求都必须落到具体课程小节。

## 当前基线

- 三课源码分别位于 `高等数学可视化/`、`线性代数可视化/`、`概率论可视化/`。
- 当前有 22 章、110 个小节；课程 README 声明 48、30、94 个可视化，共 172 个交互图示。
- 大纲原文和覆盖映射位于各课程的 `content/syllabus.js`；知识内容位于 `content/ch*.js`；可视化位于 `assets/js/widgets/`。
- 概率论的 `wrong.md` 是 2026-09-10 的审阅清单；当前源码已包含其中多项修正，因此审计以现行源码为准。当前已确认 `概率论可视化/content/ch3.js` 中一处错误：独立密度判据要求几乎处处相等，不能用单点差异直接断定不独立。
- 知序仓库存在用户既有未提交改动，尤其涉及 `README.md`、门户、共享平台、数学课程入口、平板导航和题库。实施不得覆盖或回滚这些改动；本次主要修改三课内容、覆盖元数据、课程 Canvas 组件及独立审计文档/脚本。

## 方案

采用现有原生 JavaScript 数据驱动课程结构，不更换框架、不改路由和学习进度格式。先逐条核对 2026 官方大纲和现有课程内容，再补内容，最后按知识点审阅 172 个可视化；保留有教学价值的组件，修正或增强不准确、缺少解释、控制不清或窄屏难读的组件。

课程以 2026 大纲为核心。只加入帮助理解大纲知识所需的少量延伸，并在页面中明确标为“拓展”，不计入大纲覆盖项。新例题使用原创或改编后独立表述的教学题，并完整呈现条件、步骤、结论与检验。

## 实施阶段

### 1. 知识审计

- 对照各课程大纲原文的每项考试内容与每项考试要求，分别核查覆盖位置及要求层级。
- 审阅定义、公式、条件、证明/推导、计算题、边界情形、术语、例题和跨章引用；重新计算可数值核验的结果。
- 将问题按数学错误、条件遗漏、覆盖缺口、解释不严谨、文字/引用问题分类，保留文件、小节、证据、建议和修复状态。
- 新增可复核的审计/映射记录，使每条大纲要求能追溯到课程小节；不把旧 `wrong.md` 的历史问题重复登记为当前缺陷。

### 2. 内容丰富度

- 对每个大纲原子知识点补足“概念和符号 → 成立条件/适用范围 → 关键推导或方法 → 例题完整过程 → 易错辨析 → 自检”的学习链条。
- 根据大纲动词区分了解、理解、掌握、会用的深度；为每节补上与大纲条目的一对一或可核查的一对多映射。
- 补充必要的前置知识、步骤之间的理由和跨节联系，保持公式可读、题目条件完整、数值过程可复算。
- 保留现有小节 ID、hash 锚点、课程目录结构和用户学习进度键。

### 3. 动画优化

- 逐一核对每个可视化与其知识点的对应关系、公式/参数含义、状态变化、边界条件和动画结论。
- 对需要演示过程的图示改善状态顺序、标签、单位、图例、反馈和控制；按需提供播放、暂停、单步、重置、速度调节与参数说明。
- 让每帧反映数学状态，避免误导性插值、尺度跳变、遮挡或纯装饰自动运动。对不适合连续运动的内容使用离散步骤或直接比较。
- 维护 Canvas 主题联动、键盘可达性、手机布局和减少动态效果设置；页面隐藏时停止无用动画。

## 数据流与文件职责

- `content/syllabus.js`：官方条目与课程目录；仅在完整覆盖映射或层级标注需要时修改。
- `content/ch*.js`：结构化讲解、公式、例题、易错点和知识点到小节的链接。
- `assets/js/widgets/*.js`：对应小节的 Canvas/交互组件；复用课程既有绘图库和 `widgets/ui.js` 控件。
- `docs/math-curricula/`：审计结果与大纲覆盖映射，便于复核本轮发现和修复。
- `scripts/`：仅当现有审计无法机械验证原子条目映射时，新增一个独立、无外部依赖的覆盖检查器；不改共享门户、后端、题库或其他四科。
- `scripts/build.cjs`：唯一站点构建入口，生成全站 `dist/`。

## 验收

- 22 章、110 个小节均保持可达；大纲的 349 个原文条目（226 项考试内容与 123 项考试要求）全部能追溯到课程小节，并保留原有要求层级。
- 审计中确认的数学错误、条件遗漏、例题错误和引用问题均有明确修正或理由；审计记录不留未处理的高优先级项。
- 三课内容逐节按结构检查，例题完整可复算，易错解释不与定义/结论矛盾；大纲外材料均有独立标记。
- 172 个可视化逐个审阅。发布构建中无缺失组件或脚本错误；使用浏览器核查三课的代表性过程动画、参数边界、主题、手机布局与减少动态效果表现。
- 运行现有课程内容审计和构建；只发布本轮明确修改的三课静态资源及必需配套文件，不部署全站 `dist/`，不发布知序后端或博客。
- 发布前在 `/www/backups/recaord/` 创建带时间戳的线上目录备份；通过暂存目录和 SHA-256 清单验证后切换，线上检查首页、三课入口和修正内容。

## 自查与范围边界

此设计把三课作为同一套课程结构下的三个隔离数据域；共享校验规则和发布流程，不修改其余四科。用户的直接发布授权覆盖源码修改和上述静态站点发布。现有工作区改动保持原样，也不随本轮数学资源发布；部署清单只含本轮实际修改的文件，避免夹带正在进行的门户、题库或导航改动。若这些改动影响构建，先判断是否与本轮文件有关，不擅自撤销用户改动。
