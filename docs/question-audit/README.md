## 典型问题与处理

- 操作系统硬链接题同时有两项正确，且未考虑已打开文件引用；BGP题把两个不同分类维度同时作为正确选项。均重写为唯一答案。
- 数据结构插入平均次数缺等概率位置前提；BF比较计数有“成功前是否包含成功尝试”的歧义；遍历重建缺结点互异、KMP缺下标约定、负环缺源可达条件。补齐条件及计数口径。
- 组成原理存在PC无条件加1、DMA必然中断、数据转换类型与位宽缺前提、多项容量表达同时正确等问题。删除坏版本或用独立参数重写。
- 网络PPP填充未区分异步/同步，FTP数据端口未限定主动模式，TCP关闭被写成必须四段，确认号忽略ACK标志/初始序号，SR缓存未限定当前窗口。补上协议条件。
- 线代初等行变换后直接取对角线乘积忽略换行/倍乘因子，对角化漏数域。概率题缺矩存在条件，CLT漏有限非零方差，把连续样本似然当事件概率，断言近似误差必单调下降。已修订。
- 高数非严格单调必有反函数、最值漏不可导点、积分既能求面积又能求周长导致多解、无旋必保守遗漏区域拓扑、光滑必等于Taylor级数、任意n阶ODE必有n自由常数等断言被修正。新增题使用可直接求导、积分、代入或构造反例的实例。

## 出处和题目身份

旧496条来源记录没有逐题原卷对应证明。年份、题号和链接只能提供线索，不能证明被改写后的题目仍对应该原题。本轮全部撤除未经认证的真题标签：重复/错位题删除，知识成立且有价值的题归普通考点练习。当前不提供标称真题；不把这些保留考点题冒称为新创作的原题。

未修改题保留ID，修订题统一使用`旧ID-r2`，新增题使用`qa-20261002-*`。历史学习事件保留，新提交附题库版本`question-quality-20261002-r2`。历史仅保存判分结果的事件不能恢复用户所选选项来可靠重判，本轮不删除或改写历史事件。
