## 确定错误修复

1. 系统调用须先传参数再陷入；硬件保存断点/状态，软件另存所需通用寄存器。异常含主动陷阱，不能全称被动。
2. 就绪等待时间须扣除I/O等阻塞；SJF最优论断补上同时可运行等模型前提；反馈队列按教材说明高层排队、片用尽降级、末级RR。
3. 记录型信号量只有值为负时，其负值才是等待人数；补正等待队列空间规模和安全向量解释。
4. 页号除法须取下整，段号和偏移须分别检查；CLOCK普通命中不推进扫描指针；缺页EAT明确是否包含重试。
5. 原缓冲正文把C/M物理含义颠倒，widget双缓冲实算为`max(C,M)+T`。统一T输入、M搬运、C处理，双缓冲改`max(T,C+M)`，流程图显示搬运与处理串行，并分别显示两块首尾和稳态周期。
6. 原SCAN widget实际不走端点，属于LOOK行为。现上行后有下行请求时到199再返回；C-SCAN返程距离计入，平均距离除实际请求数而非端点路径数。
7. 分页/分段widget原把越界下标取模到已有表项，产生错误映射。取消取模，显示页号、段号与段内偏移越界；采用16位输入及可出现偏移违例的段长。
8. SSTF原例未给确切结果且称“近似”；补精确请求顺序和248磁道总长度。银行家例明确(3,3,2)是Available而非全部资源总量。
