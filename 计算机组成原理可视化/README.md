# 计算机组成原理 · 交互可视化

408 计算机组成原理的交互学习项目，知识主线参考王道《计算机组成原理》，覆盖第 1~7 章。

## 内容范围

| 章 | 内容 | 主要可视化 |
| --- | --- | --- |
| 1 | 计算机系统概述 | 冯·诺依曼结构、性能指标计算器 |
| 2 | 数据的表示和运算 | 进制转换、原反补移码、补码溢出、IEEE 754、浮点加减、加法器 |
| 3 | 存储系统 | 存储层次、主存扩展、Cache 映射与访问模拟、虚拟地址转换 |
| 4 | 指令系统 | 指令格式、寻址方式、扩展操作码 |
| 5 | 中央处理器 | 单总线数据通路、微程序控制器、流水线时空图 |
| 6 | 总线 | 总线结构、同步/异步定时时序 |
| 7 | 输入/输出系统 | I/O 接口、程序查询、中断流程、DMA、三种方式对比 |

## 目录结构

```text
index.html                    入口
assets/css/main.css           样式
assets/js/lib/draw.js         Canvas 绘图引擎（Scene / Plot / 图元）
assets/js/lib/bits.js         进制、补码、IEEE 754 数值工具
assets/js/widgets/ui.js       控件外壳（滑块 / 分段 / 读数 / 单步播放）
assets/js/widgets/co1-7.js    各章交互组件
assets/js/app.js              路由 / 渲染 / 进度 / 搜索 / 主题
content/syllabus.js           章节结构与考点覆盖
content/ch1-7.js              各章知识块、例题、易错点
```

## 约定

- 本目录依赖根目录的 `platform/`，交付时请使用整站 `dist/`，不要单独复制本目录。
- 主题由 `window.Zhixu.Theme` 统一控制，Canvas 通过 CSS 变量取色，深浅色自动重绘。
- 学习进度保存在浏览器本地键 `zhixu-co-progress-v1`，不含账号与上传。
- 可播放组件在离开页面时由 `Draw.prune()` 释放计时器与观察器。

## 本地预览

在仓库根目录执行 `npm run dev`，访问 http://127.0.0.1:8766/ 后选择「计算机组成原理」。
